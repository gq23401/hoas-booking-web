# HOAS Booking — Frontend

Next.js 15 tenant UI for booking laundry machines and saunas. Nordic Utility design aesthetic.

**Backend:** [hoas-booking-backend](https://github.com/gq23401/hoas-booking-backend)

## Stack
- Next.js 15 + TypeScript + Tailwind CSS
- Syne + DM Sans typography
- JWT auth with localStorage token storage

## Run locally
```bash
npm install && npm run dev
# Open http://localhost:3000
# Demo: tenant@test.com / password123
```
